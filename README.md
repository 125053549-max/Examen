# Análisis de Datos de Sensores Industriales

Este proyecto analiza lecturas de temperatura de sensores en plantas industriales.

## Estructura del Proyecto

```text
.
├── data/
│   ├── mediciones.csv
│   └── alertas.csv
├── env/
├── .gitignore
├── requirements.txt
├── analisis.py
├── README.md
└── respuestas.md
```

## Instrucciones de Ejecución

1. Activar entorno virtual:
   ```bash
   source env/bin/activate
   ```
2. Ejecutar análisis:
   ```bash
   python3 analisis.py
   ```
